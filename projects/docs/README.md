# Triển khai theo ngày

Mỗi file ghi lại phần đã triển khai trong `projects/` ở ngày tương ứng: phạm vi, migration, API, dữ liệu fixture, kiểm tra và giới hạn. Không đặt nội dung triển khai chi tiết mới vào `../README.md`.

## Quy ước cập nhật

Khi hoàn thành một ngày mới:

1. Tạo `ngay-XX-ten-chuc-nang.md` trong thư mục này.
2. Ghi API, schema/migration, fixture, luồng UI và giới hạn chưa triển khai.
3. Thêm liên kết vào bảng trong `../README.md`.
4. Giữ README gốc cho yêu cầu môi trường, cài đặt, khởi động và lệnh kiểm tra chung.
